## Number Guessing Game – Python Project

The **Number Guessing Game** is a simple interactive Python project that generates a random number between **1 and 100** and challenges the user to guess it. The program takes the user's input, compares it with the randomly generated number, and provides feedback such as **“Too Low”** or **“Too High”** until the correct number is guessed.

### Key Features

* Generates a random number between **1 and 100** using Python's `random` module.
* Allows the user to enter their guess through the keyboard.
* Compares the guessed number with the generated number.
* Displays **Too Low** or **Too High** hints.
* Counts the number of attempts made by the user.
* Handles invalid inputs using `try-except`.
* Displays a congratulatory message when the correct number is guessed.
* Simple, interactive, and beginner-friendly Python project.

### Technologies Used

* **Python**
* **Random Module**
* **Conditional Statements**
* **While Loop**
* **Exception Handling**

### Learning Outcomes

This project helps in understanding **random number generation, user input, loops, conditional statements, functions, variables, and exception handling** in Python.
